 ###TOTOLEARN 
 
 #Interactive Toddler Learning System Using Animation, Sound and Gamified Educational Activities
TotoLearn is an interactive Android learning application designed to support early childhood learning for toddlers aged 2–5 years.
The application uses animation, sound, speech interaction, and gamified educational activities to make learning more engaging and enjoyable for young children.
The system provides learning activities in English, Kiswahili, and Mathematics, with progress tracking and practice activities to help children improve on questions they previously answered incorrectly.

# Project Objectives

The main objectives of TotoLearn are to:

* Develop an interactive toddler learning application using animation, sound, and gamified educational activities.
* Validate the effectiveness and usability of the application in supporting early childhood learning.

 # How TotoLearn Works

The learner selects a learning area and begins an interactive activity.

For speech-based activities:

1. The application presents a word or learning item.
2. The learner can listen to the pronunciation.
3. The learner responds using speech.
4. TotoLearn processes the response.
5. If the answer is correct, the learner receives a reward.
6. If the answer is incorrect, the item is saved for practice.
7. The learner automatically proceeds to the next activity.
8. Missed items can later be reviewed in the practice section.


 Getting Started

# Prerequisites

Before running TotoLearn, install:

* Android Studio
* Android SDK
* Kotlin
* An Android device or Android Emulator

# Installation

1. Clone the repository:

```bash
git clone https://github.com/logannkirote/TotoLearn.git
```

2. Open the project in **Android Studio**.

3. Allow Android Studio to sync the Gradle files.

4. Connect an Android device with USB debugging enabled or start an Android Emulator.

5. Click **Run ▶** in Android Studio.
